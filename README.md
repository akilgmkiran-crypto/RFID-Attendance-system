RFID Attendance System

Project Overview

This project uses an Arduino UNO, an RC522 RFID reader, and a 16x2 I2C LCD to identify students using RFID cards.

Components Used

* Arduino UNO
* MFRC522 RFID reader
* 16x2 I2C LCD
* RFID cards
* Jumper wires
* USB cable

Features

* Reads RFID card UIDs
* Identifies registered students
* Displays student names on the LCD
* Prints attendance status to the Serial Monitor
* Displays an unknown-card message for unregistered cards

Libraries Required

* SPI
* MFRC522
* Wire
* LiquidCrystal_I2C

How to Run

1. Install the required libraries in Arduino IDE.
2. Connect the Arduino UNO, RFID reader, and LCD.
3. Open the Arduino sketch.
4. Select the correct board and COM port.
5. Upload the code.
6. Scan a registered RFID card.
